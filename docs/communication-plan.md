## 2. Правила эскалации

Менеджер проекта (Анна) сообщает спонсору (преподавателю) сразу, не дожидаясь статус-отчёта, если:
- Работа на критическом пути (например, сбор данных или модель спроса) задерживается больше чем на 2 дня.
- Расход резерва на риски превышает половину.
- Выясняется, что цель текущего спринта недостижима из-за внешних факторов (например, недоступность открытых данных или отсутствие ответа от Администрации).
- У команды возникает конфликт интересов или блокирующая техническая проблема.

```markdown
| Измерение | Статус | Комментарий |
|---|---|---|
| Сроки | | План / факт по вехам, использование буфера |
| Бюджет | | Накопленные затраты: план / факт |
| Содержание | | Закрыто SP: план / факт, изменения |
| Риски | | Новые и изменившиеся |

## Сделано за спринт
## План на следующий спринт
## Нужна помощь спонсора
```
