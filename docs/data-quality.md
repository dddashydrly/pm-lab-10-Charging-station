## Заключение об осуществимости

Данных о **текущих** зарядных станциях недостаточно (в OSM отмечена всего 1 станция). Однако данных о **спросе** (парковки — 1314 шт., ТЦ — 45 шт.) достаточно для построения модели рекомендаций по размещению.

**Итог:** Данных достаточно с серьёзными оговорками. В связи с этим в план вносятся изменения: анализ существующего покрытия отменяется, вместо него модель будет опираться на потенциальный спрос (точки притяжения).
