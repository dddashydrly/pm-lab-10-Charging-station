## Повестка
Обсудить алгоритм скоринга для US-2 (Ранжированный список), чтобы не затягивать Sprint 2.

## Принятые решения
1. **Формула приоритета:** Приоритет = (Балл спроса) - (Балл предложения). 
2. **Факторы спроса:** Из-за отсутствия трафика в OSM используем плотность парковок и количество ТЦ в радиусе 500 м.
3. **Факторы предложения:** Используем данные о существующих ЭЗС (их мощность не учитываем из-за отсутствия данных).
4. **Техническая реализация:** Расчет будет производиться в `notebooks/04_plan_calculator.ipynb` (или напишем функцию в `src/`).
