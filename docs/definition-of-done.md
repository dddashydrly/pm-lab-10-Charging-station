## Definition of Ready (задача готова к работе)

Задачу можно брать в спринт, если:
- [ ] у неё есть понятная цель и критерии приёмки; 
- [ ] она привязана к эпику, у неё есть приоритет MoSCoW;
- [ ] известно, какие данные нужны и где они лежат;
- [ ] задача помещается в один спринт;
- [ ] зависимости сняты или известно, когда они будут сняты.

## Definition of Done (задача выполнена)

### Для любой задачи
- [ ] выполнены все критерии приёмки;
- [ ] изменения влиты в main через PR с одобрением другого участника;
- [ ] обновлена документация, если изменилось поведение системы или структура данных.

### Для задач с данными
- [ ] источник данных и дата загрузки записаны в `data/sources.md`;
- [ ] сырые данные не загружены в Git;
- [ ] скрипты обработки запускаются без ошибок;
- [ ] пропуски и аномалии отражены в отчете о качестве.

### Для пользовательских историй
- [ ] на карте присутствует легенда данных;
- [ ] интерфейс корректно отображается на экранах разной ширины;
- [ ] работа карты проверена в браузере.
