# Устав проекта: Размещение зарядных станций электромобилей

Версия 1.0 · Дата: 3.10.2026 · Авторы: Анна П., Дарья С., Дарья А. · Статус: на согласовании

Версия 1.1 · Дата: 28.10.2026 · Авторы: Анна П., Дарья С., Дарья А. · Статус: обновлено после сбора данных


## 1. Проблема и ценность
У владельцев электромобилей и операторов коммерческого электротранспорта есть проблема неравномерной доступности зарядной инфраструктуры, из-за которой поездки за пределы города и по регионам становятся рискованными, а бизнес вынужден строить собственные станции или менять графики. Сейчас это решают строительством новых станций, но размещают их стихийно — большинство сосредоточено в Москве и Московской области, а регионы и трассы остаются без покрытия. Это не работает, потому что решения принимаются без учёта реального спроса, транспортных потоков и технических возможностей подключения.

Подробнее — в [business-case.md](business-case.md).

## 3. Границы проекта
**Входит:**
- Сбор открытых данных о транспортных потоках, плотности населения и существующих зарядных станциях
- Модель оценки спроса на зарядку по районам и участкам трасс
- Приоритизированный список площадок для размещения новых станций (не менее 30)
- Интерактивная карта с существующими и рекомендуемыми станциями
- Документация: устав, бизнес-кейс, README, инструкция по запуску

**Не входит:**
- Мобильное приложение для водителей
- Реальная интеграция с платёжными системами и операторами зарядных сетей
- Мониторинг исправности и занятости станций в реальном времени
- Физическое строительство или установка зарядных станций
- Юридическое согласование площадок с собственниками земли и сетями

## 4. Допущения и ограничения
| Тип | Описание | Как проверяем |
|---|---|---|
| Допущение | Данных о текущих зарядных станциях в OSM недостаточно, поэтому анализ будет опираться на потенциальный спрос парковки | Проверено в ЛР2 |
| Допущение | Существующие станции имеют публично доступные координаты и характеристики мощности | В OSM нет данных о мощности. Учитываем только координаты. |
| Допущение | Спрос на зарядку коррелирует с плотностью электромобилей, трафиком и точками притяжения | ЛР 5: проверим модель на исторических данных о загрузке станций |
| Допущение | Заказчик готов использовать результаты анализа для планирования бюджета | Финал семестра: защита результатов перед заказчиком |
| Ограничение | Срок проекта до конца семестра | Контроль по milestone и срокам в уставе |
| Ограничение | Команда из трёх человек, по 6 часов в неделю каждый | Учёт трудозатрат на еженедельных встречах |
| Ограничение | Только бесплатные сервисы и открытые данные, без платных лицензий | Ведём список используемых инструментов |
| Ограничение | Расчёты спроса и рейтинга площадок идут локально, без выделенных серверов и облачных вычислений | Результат воспроизводится на локальном ноутбуке команды |
| Ограничение | Используется численность зарегистрированного населения (из открытых источников администрации), а не фактическая | Зафиксировано в `data/sources.md` |

## 10. Предварительные критерии приёмки продукта
- Список приоритетных площадок, не менее 30 точек с обоснованиями.
- Модели оценки спроса учитывают не менее 4 факторов (население, трафик, существующие ЭЗС, технические возможности).
- Интерактивная карта опубликована на GitHub Pages и отображает все площадки из списка.
- Карта позволяет фильтровать площадки по приоритету.
- Расчеты выполняются одной командой.
- Все источники указаны.
- Документация заполнена: устав, бизнес-обоснование, стейкхолдеры, реестр рисков.
