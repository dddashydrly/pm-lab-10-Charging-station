# Размещение зарядных станций электромобилей

Проект по размещению зарядных станций для электромобилей в городской среде с учётом спроса, транспортных потоков и экономической эффективности.

**Вариант:** 10 и Размещение зарядных станций электромобилей · **Город:** Уфа
