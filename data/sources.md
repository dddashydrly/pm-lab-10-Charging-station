## 3. Карточки источников

### DS-01. OpenStreetMap (Зарядные станции, дороги, районы)
| Поле | Значение |
|---|---|
| **ID** | DS-01 |
| **Название** | OpenStreetMap |
| **Ссылка** | https://www.openstreetmap.org, загрузка через Overpass API (библиотека `osmnx`) |
| **Для каких вопросов** | Ключевой вопрос проекта (где ставить станции) |
| **Слои** | Зарядные станции (`amenity=charging_station`), границы районов (`admin_level=9`), дороги (`highway`) |
| **Тип / формат** | Вектор: точки, линии, полигоны; после загрузки GeoPackage |
| **Лицензия** | ODbL 1.0, подпись «© участники OpenStreetMap» |
| **CRS** | EPSG:4326 |
| **Охват / Актуальность** | Уфа, загружено 28.10.2026 |
| **Число объектов** | Зарядных станций: 1, ТЦ: 45, парковок: 1314, офисов: 4 |
| **Ограничения** | Критически мало зарядных станций в OSM (всего 1). Не все операторы вносят данные; у станций не указана мощность (`socket:*`). |
| **Оценка** | 5 / 3 / 5 / 3 / 5 / 5 = **4,3** |
| **Решение** | Использовать. Проверить полноту выборочно по открытым данным операторов. |

### DS-02. Численность населения по районам
| Поле | Значение |
|---|---|
| **ID** | DS-02 |
| **Название** | Численность населения по районам (Администрация / Росстат) |
| **Ссылка** | Официальный сайт администрации или сборник Росстата |
| **Для каких вопросов** | Оценка потенциального спроса (сколько людей живет в районе) |
| **Слои** | Табличные данные: `district`, `population`, `year`, `source` |
| **Тип / формат** | Таблица (CSV), собирается вручную в `data/manual/` |
| **Лицензия** | Официальная публикация, ссылаться можно (явной открытой лицензии нет) |
| **Охват / Актуальность** | Данные за последний доступный год |
| **Ограничения** | Указана численность *зарегистрированного* населения, а не фактического |
| **Оценка** | 4 / 4 / 4 / 3 / 2 / 3 = **3,3** |
| **Решение** | Использовать с оговорками (указать в выводах, какая численность использована). |
